# NeoZed Maintenance

This directory is the control plane for maintaining NeoZed as a product fork of Zed.

Agents must read these files before feature, bug fix, or upstream-port work:

- [Workflow](./WORKFLOW.md)
- [Fork policy](./FORK_POLICY.md)
- [Upstream base](./UPSTREAM_BASE.md)
- [Upstream review](./UPSTREAM_REVIEW.md)
- [Feature ledger](./FEATURE_LEDGER.md)
- [Agent prompts](./AGENT_PROMPTS.md)

GitHub issues are the durable source of truth. Chat prompts are used to assign a specific issue to an agent and ask it to execute the documented workflow.
